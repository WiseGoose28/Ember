# EMBER v1.1 — Personal Growth PWA

- Onboarding is separate; navigation is hidden until setup is complete.
- Goals can only be added or edited in the Goals tab.
- Every goal has its own start date and Day 1.
- Adding a goal does not reset the overall journey or existing goal history.
- Insights are goal-specific, with a selector, start date, elapsed days, completion rate, streak, check-ins and recent activity chart.
- Existing V1 data migrates automatically: goals without a start date inherit the original journey start date, preserving prior logs.

## Update
Upload these files to the root of the existing GitHub Pages repository, replacing the old files. Keep the same repository and Pages settings. The service worker cache version is updated to v1.1. If an installed app still shows the old version, fully close and reopen it; if necessary clear the site's cached data in Chrome.

All data is stored locally in the browser. Export a JSON backup before clearing site data. No cloud sync is included.
